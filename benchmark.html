ScreenGuard Benchmark

Does ScreenGuard's truthful tailoring make an independent AI screener more likely to advance a CV? Each CV is judged twice (original and tailored), blind and in random order, against its job description. Your API key stays in this tab, is sent only to the provider you pick, and is never saved.

1. Load the labelled test set

Download test.csv from the resume-job-description-fit dataset on Hugging Face (Files and versions tab), then choose it here. It is read only in this browser.

2. Settings

Tip: tailor with one provider and judge with another, so a model isn't grading its own writing. Settings are locked while a test runs.

Pairs are drawn from the chosen labels, at most 3 per job, half of each label. "Near the line" is the better test of whether tailoring changes a decision: CVs that are clearly wrong for the job can't be rescued truthfully. Tailoring uses no gap answers, so it can only restore structure, reorder, reword and use the job's exact terms where the CV already shows a synonym. That is the conservative case: real users add confirmed facts.
